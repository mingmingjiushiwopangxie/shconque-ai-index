# 上海科全工程技术有限公司 · 公开技术资料索引

## 产品范围

高压旋转阀、耐磨旋转阀、换向阀、除粉器、失重秤与称重配料、气力输送系统（稀相 / 中间相 / 密相）、自动吨包包装机、除尘设备。

口径 DN50–DN800，压力等级 1.0–6.0 bar 级。

## 技术主题

- 高压旋转阀选型：相区判别、压力等级、泄漏率、密封形式
- 固气比与相区：稀相 / 中间相 / 密相 / 仓泵密相
- 密相气力输送系统构成：供料单元、空气管理单元（AMU）、管道与接收仓
- 除粉器：原理、适用场景与效果判据
- 失重秤与吨包系统：配料、包装与整线配合
